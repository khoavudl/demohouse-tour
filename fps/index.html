🏠 Khám Phá Ngôi Nhà (Demohouse)

Trải nghiệm góc nhìn thứ nhất (FPS Walkthrough). Nhấp chuột vào nút bên dưới để bắt đầu.

W S A D / Mũi tên : Di chuyển (Giữ để đi)
Chuột : Lắc nhìn 360°
1 : Góc nhìn thứ nhất (FPS)
2 (hoặc V) : Góc nhìn Thanos (TPP)
L : Bật / Tắt đèn trong nhà
N : Đổi Ban ngày / Ban đêm
C : Bật / Tắt chống xuyên tường
Shift : Giữ để chạy nhanh
ESC : Nhả chuột / Menu
🕹️ Nửa Trái : Cần gạt di chuyển
👆 Nửa Phải : Vuốt đổi góc nhìn
👤 Nút Góc nhìn : Thanos TPP / FPS
💡 Nút HUD : Bật/tắt đèn & ngày/đêm
🏠 Điều Khiển
📍 Chuyển Phòng Nhanh
